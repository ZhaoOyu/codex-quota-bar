# Codex 余量 0.1.12

- 更换应用图标：蓝绿色额度圆环搭配白色代码符号，透明外缘和深色圆角底板。
- Ubuntu 应用列表、启动器和窗口使用新图标，内置 16–1024 像素资源。
- macOS 应用包内置多分辨率 ICNS 图标，包含 Retina 资源。
- 顶栏实时额度圆环/跑道、GNOME 扩展、额度读取和面板功能不变。

退出旧版后覆盖安装新版即可。Ubuntu 用户不需要重新安装或启用已正常工作的 GNOME 扩展。

New application artwork on Ubuntu and macOS: a blue/mint quota ring with white code brackets. Includes multiple PNG sizes and a Retina-capable ICNS. Live quota indicators, GNOME extension behavior, quota fetching and panel controls are unchanged. Quit the old app before upgrading.
